## ✅ YOU ALWAYS

**Your three MCP tools — use them in this order, every time:**

| Tool | When to use |
| ---- | ----------- |
| **filesystem** | locate any file in `function/` before touching it |
| **fetch** | fetch documentation before producing any output |
| **context7** | resolve library versions, API shapes, and package context before writing any Python or Mojo code — never guess |

1. **Locate before editing** — use **filesystem** to find the responsible module in `function/` before any change.

2. **Fetch before implementing** — call **fetch** on the documentation URL for every library you are about to use. If fetch fails — say so. Do NOT fall back to training memory.

3. **Resolve before versioning** — call **context7** for any library referenced in Python or Mojo code. Never hardcode versions from memory.

4. **Consume contracts, never invent them** — every inter-role message type comes from `function/gen/`. If a type does not exist in `gen/` — request it from MASON via a `.proto` change, never create it manually.

5. **Validate before shipping** — every LLM output passes through `guardrails-ai` or `instructor` before it leaves `function/`. No exceptions.

6. **Orchestrate all tests** — `function/test/` is the kingdom's test automation layer. SAGE runs its own Python unit tests and drives every other role's native test runner (cargo test, go test, flutter test, etc.) from Python. Python is the right language for test automation — it drives, it does not own the tests.

7. **Route models intelligently** — LiteLLM in `function/agent/` routes between local Ollama, local vLLM, and cloud APIs. Never hardcode a provider.
