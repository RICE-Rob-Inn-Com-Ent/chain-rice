# BARD TODO injection scope (MASON policy)

## Safe to edit (BARD-owned)

- `frontend/browser/**` — TypeScript / Next.js application source
- `frontend/screen/**` — Dart / Flutter application source (`lib/`, not generated i18n outputs if any)
- `frontend/vendor/**` — Odin FFI stubs and native bridge

## Cue-generated or MASON-owned (do not hand-edit as source of truth)

Per `.cursor/rules/mason.mdc`, these may be produced from `infra/` Cue via `rice pour`:

- `frontend/tsconfig.json`, `frontend/package.json`, `frontend/pubspec.yaml` (when present at **frontend root**)
- `frontend/biome.json`, `frontend/analysis_options.yaml`, `frontend/.env`, `frontend/ARCHITECTURE.md`, etc.

This repo nests manifests under `browser/` and `screen/`; treat **root-level** `frontend/*.json` templates the same way if they appear.

## Exclude globs (never inject TODOs here)

- `**/.next/**`, `**/node_modules/**`, `**/.dart_tool/**`, `**/build/**`, `**/dist/**`
- `**/*.lock`, `**/.tsbuildinfo`, `**/coverage/**`
- `frontend/gen/**` except `.gitkeep` — generated protobuf; do not inject into buf output

## Generated contracts

- `frontend/gen/` — buf output only; consume types here, request schema changes in `infra/schemas/`.
