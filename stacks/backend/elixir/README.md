## Elixir Hello World

**Run (mix project)**

- `mix new hello --app hello --sup` (opcjonalnie)
- W tym przykładzie: `elixir lib/hello.ex -e Hello.main`

## Do czego najlepiej pasuje Elixir?

- Systemy rozproszone, skalowalne API, przetwarzanie strumieni (Phoenix, Broadway).
- Aplikacje o wysokiej niezawodności na BEAM (OTP, aktorzy, supervision trees).

## Kiedy rozważyć inne języki?

- Bardzo wysokie wymagania na wydajność niskopoziomową: Rust/C++.
- Ekosystem JVM lub .NET preferowany organizacyjnie: Java/Kotlin/C#.
