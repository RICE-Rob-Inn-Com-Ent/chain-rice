## Release (Mix Releases)

Budowanie i uruchamianie:

- Zbuduj: `MIX_ENV=prod mix release examples_elixir_hello`
- Uruchom: `_build/prod/rel/examples_elixir_hello/bin/examples_elixir_hello start`
- Zatrzymaj: `_build/prod/rel/examples_elixir_hello/bin/examples_elixir_hello stop`

Skrót:

- `rel/my_app` zbuduje (jeśli potrzeba) i wystartuje release.
