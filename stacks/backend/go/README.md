## Go Hello World

**Run**

- `go run ./` (domyślnie "World")
- `go run ./ Ala` (z argumentem imienia)
- Testy: `go test ./...`

## Do czego najlepiej pasuje Go?

- Proste, szybkie w kompilacji serwisy i CLI, cloud-native i DevOps tooling.
- Współbieżność (goroutines, channels), mikroserwisy, narzędzia sieciowe.

## Kiedy rozważyć inne języki?

- Złożone modele domenowe/FP: F#/Scala/Haskell.
- Maksymalna wydajność i kontrola pamięci: Rust/C++.

## Oceny (1–5 gwiazdek)

- Skala: 1 = niskie/małe, 5 = wysokie/duże.
- Poziom trudności nauki: ★★☆☆☆
- Bogactwo bibliotek/ekosystemu: ★★★★☆
- Bogactwo zastosowań w praktyce: ★★★★★
- Wydajność runtime: ★★★★☆
- Narzędzia/build: ★★★★★ (go toolchain)

## Przykładowe biblioteki i narzędzia

- HTTP: net/http, chi, gin.
- Testy: testing, testify.
- CLI: cobra, urfave/cli.
- Modules: go mod.
