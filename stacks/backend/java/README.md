## Java Hello World

**Build & Run**

- Gradle: `./gradlew run --args "Ala"`
- Ręcznie: `javac -d out src/com/example/*.java && java -cp out com.example.App Ala`

## Do czego najlepiej pasuje Java?

- Aplikacje biznesowe, backend na JVM, narzędzia wieloplatformowe.
- Ekosystem bibliotek (Spring, Jakarta EE), świetne narzędzia i monitoring.

## Kiedy rozważyć inne języki?

- Proste CLI i krótki cykl: Go.
- Niskopoziomowe/wysokowydajne: Rust/C++.
