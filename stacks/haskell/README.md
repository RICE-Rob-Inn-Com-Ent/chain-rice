## Haskell Hello World

**Build & Run**

- GHC: `ghc -o main src/Main.hs && ./main`
- Stack: `stack run`

## Do czego najlepiej pasuje Haskell?

- Programowanie funkcyjne z silnym typowaniem, DSL-e, kompilatory.
- Przetwarzanie danych/strumienie, logika biznesowa o wysokiej niezawodności.

## Kiedy rozważyć inne języki?

- Szybki onboarding zespołu i bogaty ekosystem web: TS/Java/C#.
- Niskopoziomowe komponenty/systemy: C/C++/Rust.
