## F# Hello World

**Build & Run**

- `dotnet build`
- `dotnet run --project MyApp.fsproj`
- Skrypt: `dotnet fsi script.fsx`

## Do czego najlepiej pasuje F#?

- Modelowanie domeny i czysta logika biznesowa (silne typowanie, pattern matching).
- Programowanie funkcyjne na platformie .NET (interop z C# i ekosystemem NuGet).
- Przetwarzanie danych, skrypty i automatyzacja (fsi, notebooki .NET).

## Kiedy rozważyć inne języki?

- Klasyczne projekty .NET w zespołach nie-FP: C#.
- Systemy niskopoziomowe/wysokowydajne: Rust/C++.
- Ekosystem data science/ML: Python/Julia.

## Oceny (1–5 gwiazdek)

- Skala: 1 = niskie/małe, 5 = wysokie/duże.
- Poziom trudności nauki: ★★★★☆
- Bogactwo bibliotek/ekosystemu: ★★★★☆ (dzięki .NET/NuGet)
- Bogactwo zastosowań w praktyce: ★★★★☆
- Wydajność runtime (.NET): ★★★★☆
- Dojrzałość narzędzi/buildów: ★★★★★ (dotnet CLI, IDE)

## Przykładowe biblioteki i narzędzia

- Web: Giraffe, Saturn, ASP.NET Core interop.
- Dane: FSharp.Data, Deedle.
- Testy: Expecto, FsUnit, xUnit.
- Pakiety/narzędzia: dotnet CLI, Paket, FAKE.

## Jak zacząć z tym przykładem?

- Zbuduj: `dotnet build`
- Uruchom: `dotnet run --project MyApp.fsproj`
- Skrypt: `dotnet fsi script.fsx`
- Zajrzyj do `ARCHITECTURE.md`, aby zobaczyć strukturę i kierunki rozbudowy.
