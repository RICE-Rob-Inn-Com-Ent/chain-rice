## OCaml Hello World

**Build & Run**

- `ocamlc -o main src/main.ml && ./main`
- Lub z dune: `dune exec ./main.exe`

## Do czego najlepiej pasuje OCaml?

- Bezpieczne i wydajne narzędzia, kompilatory, analiza statyczna.
- Programowanie funkcyjne z silnym typowaniem i pattern matching.
