## Dart Hello World

**Build & Run**

- `dart run bin/main.dart`
- Testy: `dart test`

## Do czego najlepiej pasuje Dart?

- Aplikacje mobilne/desktop/web z Flutterem (jeden kod, wiele platform).
- Proste narzędzia CLI i skrypty z szybkim uruchamianiem.
- Aplikacje web (Dart/Flutter Web) i prototypowanie UI.

## Kiedy rozważyć inne języki?

- Backend o dużym ekosystemie JVM/.NET: Java/Kotlin/C#.
- Szybkie przetwarzanie danych/ML: Python.
- Systemy niskopoziomowe: Rust/C++.

## Przykładowe biblioteki i narzędzia

- UI: Flutter, Material/Cupertino widgets.
- HTTP: `http`, `dio`.
- JSON i serializacja: `json_serializable`, `built_value`.
- Testy: `test`, `mockito`.
- Narzędzia: `dart`/`flutter` CLI, `pub`.

## Jak zacząć z tym przykładem?

- Uruchom: `dart run bin/main.dart`
- Testy: `dart test`
- Zajrzyj do `ARCHITECTURE.md` aby zobaczyć, jak rozbudować projekt (`lib/`, testy).
