## Makefile – projekt przykładowy

**Uruchomienie**

- `make hello`
- `make build && ls dist/`
- `make clean`

## Do czego najlepiej pasuje Make?

- Orkiestracja kroków build/test/deploy, komendy skryptowe, CI.
- Proste zależności plikowe i cache kompilacji.

## Kiedy rozważyć inne narzędzia?

- Wieloplatformowe buildy i dependency graph: Bazel/pants/Gradle.
- Projekt w JS/TS: skrypty npm/pnpm/yarn.

## Oceny (1–5 gwiazdek)

- Skala: 1 = niskie/małe, 5 = wysokie/duże.
- Poziom trudności nauki: ★★★☆☆
- Elastyczność/uniwersalność: ★★★★☆
- Zastosowania w praktyce: ★★★★★
- Czytelność dużych projektów: ★★★☆☆
