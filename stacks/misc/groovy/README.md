## Groovy Hello World

**Uruchomienie**

- `groovy src/main/groovy/App.groovy`

Albo z Gradle:

- `./gradlew run` (Linux/macOS) lub `gradlew.bat run` (Windows)

## Do czego najlepiej pasuje Groovy?

- Skrypty na JVM, automatyzacja buildów (Gradle), szybkie prototypy.
- Integracja z bibliotekami Javy przy dynamicznej składni.

## Kiedy rozważyć inne języki?

- Wydajne, statyczne mikroserwisy: Java/Kotlin/Go.
- Niskopoziomowe komponenty: Rust/C++.
